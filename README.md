# Apogee Information Systems

Open-source tools and developer resources from [Apogee Information Systems](https://apogee.lu/).

This repository hosts the public GitHub org landing page ([apogee.lu/github](https://apogee.lu/github/)).

## Open-source packages

| Package | Description |
| --- | --- |
| [pagespeed-watcher](https://github.com/Apogee-Information-Systems/pagespeed-watcher) | Laravel package for Google PageSpeed Insights checks — CLI validation, usage tracking, and scheduled performance tests |
| [website-404-redirects](https://github.com/Apogee-Information-Systems/website-404-redirects) | Laravel 11/12 package to log 404 paths and manage 301 redirects from the database |

## Developer tools

- **[Apogee Watcher](https://apogeewatcher.com/)** — PageSpeed monitoring for agencies and freelancers (Core Web Vitals, CrUX, budgets, white-label reports)
- **MailOps** — Modoboa extension for mail-server observability and delivery diagnostics
