Core Web Vitals Checklists

Apogee-Information-Systems / core-web-vitals-checklists

Index of Apogee open-source templates and checklists for Core Web Vitals monitoring. Start at the index repository, then open the repo that matches how you want to work — a light GitHub Issues SOP (Standard Operating Procedure), a full agency playbook, or a single artefact such as performance budgets or client reports.

View index on GitHub

// Monitoring SOP (Standard Operating Procedure)

  • cwv-monitoring-checklist — Fork-friendly checklist and issue forms; light SOP (Standard Operating Procedure) to copy or run as GitHub Issues. Read more on our blog Core Web Vitals Monitoring Checklist for Agencies
  • agency-cwv-playbook-template — Full playbook (runbooks, clients, ops); one ops repo per agency (Use this template). Read more on our blog Core Web Vitals Monitoring Checklist for Agencies

// Templates and checklists

Each repository pairs with an Apogee Watcher article that explains how to use the template in production.

  • performance-budget-thresholds-template — Define and document performance budget thresholds for client sites. Read more on our blog Performance Budget Thresholds Template
  • slack-alert-policy-template — Slack alert policy for web performance teams: severity, routing, and response expectations. Read more on our blog Slack Alert Policy Template for Web Performance Teams
  • client-cwv-report-outline — Client-ready Core Web Vitals report outline for recurring delivery. Read more on our blog Client-Ready Core Web Vitals Report Outline
  • monthly-performance-review-template — Monthly performance review template for agency teams running multi-client portfolios. Read more on our blog Monthly Performance Review Template for Agency Teams
  • site-audit-checklist-performance-onboarding — Site audit checklist for onboarding a new client for performance monitoring. Read more on our blog Site Audit Checklist: Onboarding a New Client for Performance Monitoring
  • performance-monitoring-roi-calculator — Spreadsheet-style ROI framing for agencies selling or justifying monitoring work. Read more on our blog Performance Monitoring ROI Calculator for Agencies
  • performance-review-meeting-agenda — Meeting agenda for structured performance review sessions with clients or internal teams. Read more on our blog Building a Performance Review Meeting Agenda
